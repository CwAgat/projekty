### Dashboard jakości powietrza — PM10, PM2.5, NO2
**Autorki:** Agata Ćwikła, Zofia Gil, Joanna Heyda | **2026**

Interaktywny dashboard w ArcGIS Online prezentujący stężenia PM10, PM2.5 i NO2 dla 6 stacji pomiarowych w Polsce.
Dane pobierane automatycznie co godzinę z API GIOŚ skryptem Python uruchamianym przez harmonogram ArcGIS Online; warstwa mapowa aktualizowana w czasie rzeczywistym.
Wyniki i wykorzystane technologie:dashboard/panel z web mapą, wykresami, wskaźnikami i pop-upami z oceną jakości powietrza (wyrażenia Arcade).
